# Mixed-point circuits: a frame criterion, but no new exponent

> **Historical research, reconciled October 8, 2026.** Numerical uses of “current,”
> “retained,” and “next” below refer to this experiment’s checkpoint. For the
> published bound and active contracts, see [current status](current-status.md).
> These scoped experiments do not supersede later community constructions.

**The integrated multiplication witness remains `2^-31`.** This bounded
round changes the scalar computation across common-point groups. It finds a
12.1% scalar role reduction and a reusable rational-frame construction that
passes complete small controls. The full-size role count still misses the
`2^-30` target even if every new side transition is charged optimistically
as increasing. A full-size frame certificate is therefore not claimed.

This is a different search from relabeling the paired modules. Transposing
and factoring a complete circuit changes which sums are formed, so the earlier
paired-template obstruction does not apply.

## Three bounded constructions

The scalar operator is the intersection-one matrix on triples. Every addition
has disjoint formal support; scalar arithmetic is XOR, but no cancellation is
used. The reversible compiler still uses `R=c+q` roles, where `c` counts binary
additions and `q` counts designated output uses.

1. **Block decomposition.** For a relation between k-subsets and l-subsets
   with intersection size r, split the ground set into two blocks. Separate
   cases by source/target cardinalities in each block and their intersection
   sizes. Apply the two smaller maps as a tensor product, choosing the cheaper
   evaluation order, and combine disjoint cases. The dynamic program considers
   all split sizes. Kernels include direct sums, shared vector subset/complement
   sums, transposed vector maps and the existing paired exclusion circuit.
2. **Hybrid decomposition.** Also allow decomposition by the unique common
   point when r=1. This keeps the older construction wherever block processing
   would cost more. The planner minimizes its explicit composition count;
   exact support interning can further reduce the materialized graph. It is
   not a globally optimal circuit search.
3. **Factored transposition.** Reverse the complete linear computation: a
   node's adjoint sums the adjoints of its consumers. A symmetric top-level
   matrix permits iteration. Collapse single-use aliases, greedily factor
   repeated pairs of summands across these sums, then materialize the new
   cancellation-free circuit. Four rounds are the explicit stopping budget.

Transposition preserves the operator here because the intersection-one matrix
is symmetric. It creates genuinely mixed-point intermediates after sharing
between common-point modules. Repeated-pair factoring changes the graph,
rather than merely reordering the original paired modules. Its scalar validity
does not establish its frame validity.

## A source/target-span cut lemma

The new frame construction is useful independently of this failed count target.
Let the ambient rational space have its nondegenerate form `I-J/9` (h != 9).
At a scalar DAG node v, define:

- S_v: the span of its source triple indicators;
- T_v: the span of target indicators reachable from it.

A correct cancellation-free intersection-one circuit has S_v orthogonal to
T_v: every reachable source/target pair intersects in exactly one point.
For an edge u -> v,

    S_u subset S_v,     T_v subset T_u.

The old construction used S_v as the frame. This fails when S_v is degenerate.
Instead, let C be the forward-closed set generated by all nodes with degenerate
S_v. If **T_v is nondegenerate for every v in C**, define

    E_v = S_v          outside C,
    E_v = T_v-perp     inside C.

Then every E_v is nondegenerate and

    S_v subset E_v subset T_v-perp.

Moreover every edge is increasing. For two nodes outside C, use source-span
inclusion. For two nodes inside C, use reversed target-span inclusion and
orthogonal complements. For an edge entering C, use
`S_u subset S_v subset T_v-perp`. An edge leaving C is excluded by forward
closure. This proves the criterion.

### Transfer into the retained network

Each source input starts with its nondegenerate triple line, so it is outside
C. Each output frame is contained in its target line's orthogonal complement.
Use E_v as the middle gate frame in the forward computation and E_v-perp in
the reversed computation. The latter frames increase along reversed edges.
All incident roles at a gate have the same frame. Newly allocated roles enter
from zero; retired roles grow to the full active factor.

The existing tensor lift `D_E=(B tensor F) orthogonal-sum (P tensor E)` supplies
the original data-stage boundaries. A nested pair of nondegenerate subspaces
has projection-difference rank equal to its dimension difference, including
for an indefinite rational form. Thus these side transitions add no decreases.
The transparent side schedule still restores arbitrary auxiliary values; the
central computation, negative source convention, endpoint correction and
first/third-stage matching are retained. A full finite circuit satisfying this
criterion therefore fits the old role/residual accounting.

This lemma is a **sufficient criterion**, not a complete characterization of
possible rational matrix frames. A failed cut may still admit other subspace
labels or a more general matrix-frame construction.

## Small exact controls: degeneracy is repairable

The checker constructs exact rational spaces using integer primitive row
reduction. It verifies all selected frame Gram ranks, every compiled forward
and reverse side-role inclusion, and the source/injection endpoint obligations.
It also runs the transparent side circuit on independent formal variables for
every source and every arbitrary scratch input, checking the whole linear map
and exact restoration.

controls; these small ground sizes do not have the retained positive global

## A genuine local enclosure obstruction

There is also a cheap rejection rule. If S_v and T_v are orthogonal but have
a nonzero intersection, there is no nondegenerate subspace E satisfying

    S_v subset E subset T_v-perp.

Indeed a nonzero vector in their intersection lies in E and is orthogonal to
all of E, making E degenerate. This rules out every such subspace enclosure,
not only the source/target cut above. It does not rule out arbitrary nonnested
rational matrix frames.

A concrete example uses three disjoint source triples on nine coordinates in
ambient dimension ten. Take as targets all 27 triples choosing one point from
each source triple. Every source/target pair is an allowed intersection-one
pair. Nevertheless the all-ones vector on those nine coordinates lies in both
spans: it is the sum of the three source indicators and one ninth of the sum
of all target indicators. The spans are orthogonal, and their intersection
has dimension one. No nondegenerate enclosure exists at a node aggregating
all three sources and serving all those targets.

The small mixed-point controls above have no nodes with this obstruction.
That absence alone would not certify them; the explicit frame cuts do.

## Decision and reproduction

Stop this bounded decomposition/transposition search. The large count gains
occur in its first two factoring rounds, and rounds three and four save only
27 and 11 more roles. More iterations are not supported by these observations;
this is an economic stopping decision, not a convergence or lower-bound theorem.

Retain the source/target-span cut lemma and checker for the next circuit
proposal. They enlarge the certifiable design space beyond positive-definite
common-point source spans. A better candidate still needs substantially fewer
roles, reduced central losses, or both. Combining final partial outputs alone
does not save roles: adding two gates per target while deleting two output
uses leaves `c+q` unchanged. New sharing must occur earlier.

Run `python3 scripts/audit_mixed_point.py`, the focused `test_mixed_point.py`
tests, or `make verify`. The [certificate](../../certificates/mixed-point-audit.json)
records full-size scalar maps, small compiled frame controls, the explicit
obstruction and source hashes. The implementation is in
[the circuit search](../../scripts/experiments/mixed_point_circuit.py),
[the rational frame checker](../../scripts/rational_span_frames.py), and
[the audit](../../scripts/audit_mixed_point.py).

No full-size mixed-point frame certificate, improved multiplication witness,
or independent verification of the upstream theorem is asserted. The existing
`2^-31` artifacts remain unchanged.
