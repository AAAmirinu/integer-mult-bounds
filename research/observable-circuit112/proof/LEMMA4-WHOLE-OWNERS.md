# Lemma: colored complete-call exchange and strict remainder concentration

Fix an admitted local provider, its exact helper entrance frames, and an explicit finite controller composed of complete normalized cover invocations. Each helper occurrence occupies one whole physical family, with a residual subspace inside one pending idle child. The complete wrapper is valid for arbitrary dirt and restores every borrowed spectator. Its source-bound ambient chart carries the specified residual and spectator axes. The controller and all such wrappers retain their existing all-size hypotheses.

Consider a new assignment obtained as follows. Within each complete invocation, permute helper identities among that invocation's existing owner slots. A slot retains its physical family, pending child, invocation time, and owner timeline. Replace its width by the actual residual dimension of the new helper. For each pending child, the sum of its new assigned widths must not exceed its rank. Repack those residual intervals contiguously inside that child's actual orthogonal axes. Rebuild each full chart using the new helper's exact frame and the actual pending axes, with the same normalized-wrapper construction; this last condition is a constructive obligation checked by the existing emitter and independent chart audit, not an assumption that arbitrary width data realizes an operator.

Then the new assignment is sufficient for a legal composition under the same normalized-cover contracts. Indeed:

1. Every invocation uses the same set of whole families, so helper-owner injection and disjointness from active data are unchanged.
2. Each owner slot remains at its old time on its old idle interval. Thus no new chronology obligation arises.
3. Repacking yields disjoint residual coordinate supports inside each pending child. Their operators commute because they act on disjoint coordinates. Their product followed by the explicitly charged remainder equals that pending child's original operator.
4. Full wrappers restore borrowed spectators after each complete invocation. Spectators can overlap other uses at different invocation times without changing the endpoint. No scalar gate is commuted through a recursive call and no within-invocation interleaving is introduced.
5. Helper permutation merely changes which whole chart realizes each source helper. Source local instruction order, complete dirty restoration, physical family inventory, and all local scalar charges remain fixed. The actual charts, labels, and finite prefix invoice must still be reconstructed and audited.

The exact global recursive histogram therefore equals the sum of all actual local invocation histograms plus one child of rank q for each positive remainder q. No residual is split into separately hosted oracle calls and no unpaid bank family is introduced.

## Strict gain from a two-slot exchange

Choose two slots in the SAME complete invocation but in different pending children. Let their current widths be u,v, their child remainders x,y, and d=v-u. Swapping the helpers changes the remainders to x-d,y+d. This is admissible exactly when these remainders are nonnegative (all other slot conditions above remain inherited). If the sorted new pair strictly majorizes the old pair, namely

    min(x-d,y+d) < min(x,y),    (x-d)+(y+d)=x+y,

then for every real exponent 0<a<1,

    (x-d)^a + (y+d)^a < x^a + y^a.

Proof: write the pairs as (s,S-s) and (t,S-t), with 0<=t<s<=S/2. The function g(z)=z^a+(S-z)^a is strictly increasing on [0,S/2]; on the open interval its derivative is a(z^(a-1)-(S-z)^(a-1))>0, and continuity includes zero. Hence g(t)<g(s).

Thus each certified exchange strictly decreases the global recurrence moment for EVERY exponent in (0,1), not merely at the floating-point nomination exponent. At an old certified moment root b in (0,1), the new moment is strictly below the same live-stock threshold, and continuity/strict monotonicity yields a strictly larger root. Exact rational moment evaluation and outer assembly remain necessary to publish a numerical kappa.

Arbitrary within-call permutations decompose into cycles. The same sufficiency argument applies to a simultaneous colored cycle whenever all affected child capacities and the exact final histogram are checked. The first-stage exchange witness uses twenty length-two cycles, each with the strict integer majorization certificate above; no unproved longer-cycle gain is claimed.
