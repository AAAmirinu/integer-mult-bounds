# Replay and browser transport

Run the root verifier with Python 3.11 or later and assertions enabled:

    python -B verify.py --work /absolute/path/to/a-new-output-directory

The output directory must not exist and must lie outside this package. All
source fixtures and exact arithmetic engines are included; no network or search
optimizer is used. A full run takes several minutes on the tested Windows CPU.
It writes each stage log, a stage ledger, the emitted programs/charts, independent
audits and RESULT.json. Do not use the historical vendor entrypoint as this
derivative's test.

The final complete run was executed on Windows Python 3.11 from a separate copy
with all recognized text converted to CRLF. All 27 stages passed, including both
exact moment engines, all 47 strict inequalities and comparison to EXPECTED.json.
All executable sources and inputs in this package were compared to that replay
copy; only documentation and receipts were added afterward. This is not a claim
of testing Python 3.14, Linux or macOS locally.

Manifest hashes normalize only text line endings; binary fixtures remain exact.
Generated gzip pins level 9, timestamp zero and OS byte 255. Missing manifest,
missing expected result, missing input, changed token and optimized Python reject
before creating an output directory. Mathematical controls separately reject
92 omitted kernel corrections, 19 owner/controller corruptions, invalid outer
parameters and the adjacent exponent endpoints.

batches before opening one PR. The upload set has no hidden files, at most 40
files per batch and no file >=2MB. Its reassembled bytes and manifest are checked.
